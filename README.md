# 창원 날씨 분석 (2021-2025)

창원 ASOS 지점 155의 일별 관측자료를 이용해 2021년부터 2025년까지의 기온과 강수량을 탐색·시각화한 프로젝트입니다. 2026년은 아직 완결되지 않아 분석에서 제외했습니다.

## 분석 내용

- 연도별 월평균기온 꺾은선 그래프
- 연도별 월강수량 막대그래프
- 연도·월별 평균기온 히트맵
- 월별 일평균기온 상자그림
- 월평균기온과 월강수량 산점도
- 12개월 이동평균, 전년 동월 기온 차이와 강수량 변화율
- 결측치·이상치 기준, 주요 수치 인사이트와 한계

자세한 분석 질문, 데이터 설명, 인사이트 및 한계는 [REPORT.md](REPORT.md)를 참고하세요.

## 프로젝트 구성

- `창원날씨.ipynb`: 데이터를 불러오고 그래프와 시계열 분석을 실행하는 노트북
- `REPORT.md`: 분석 방법, 수치 근거가 포함된 인사이트, 결론과 한계
- `data/raw/`: 연도별 분석용 CSV 5개
- `data/archives/`: 내려받은 원본 ZIP 5개
- `requirements.txt`: Python 분석·노트북 의존성

CSV는 CP949 인코딩으로 읽습니다. 원본 압축 파일은 보존하며, 그래프 생성 중 결측 기상값을 임의로 0이나 평균으로 채우지 않습니다.

## 실행 방법

PowerShell에서 프로젝트 폴더로 이동한 다음:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
jupyter notebook 창원날씨.ipynb
```

VS Code를 사용하는 경우 Python 및 Jupyter 확장을 설치하고 `.venv`를 커널로 선택한 뒤 노트북 셀을 위에서부터 실행하면 됩니다.

가을철(9-10월) 늦더위: 특히 9월 기온의 경우, 2021년-2023년에는 $24-25^\circ\text{C}$ 수준이었으나 2024년에는 $26.5^\circ\text{C}$ 부근까지 크게 상승하며 가을철 늦더위 현상이 뚜렷하게 나타났습니다.

연도별 편차: 같은 달이라도 연도에 따라 강수량 차이가 수백 mm 이상 벌어지는 등 변동성이 매우 심합니다.
집중호우 및 가뭄 패턴:
극심한 가뭄 (2022년): 2022년은 봄부터 여름, 가을까지 전반적으로 월강수량이 예년에 비해 월등히 적어(가장 비가 많이 온 달도 200mm 수준) 대표적인 건조/가뭄 해였습니다.
특정 달 집중호우:
2021년 7월: 월강수량 500mm 돌파
2023년 7월·8월: 2개월 연속으로 450~500mm 이상의 기록적인 폭우 발생
2024년 9월: 가을철임에도 불구하고 500mm가 넘는 이례적인 집중호우 기록

Q3. 월평균 기온과 월강수량 간에는 어떠한 상관관계가 존재하는가?
양(+)의 상관관계 (기온 상승 시 강수량 증가):

반면, 월평균 기온이 $20^\circ\text{C}$를 넘어서는 고온기(여름~초가을)에 접어들수록 강수량이 급격히 늘어나는 경향을 보입니다.
고온기 강수량의 불확실성/변동성 확대:
기온이 $25^\circ\text{C}$ 이상인 구간에서는 월강수량이 100mm 대부터 500mm 이상까지 매우 넓게 분포합니다. 이는 기온이 높을수록 대기 중 수증기량이 늘어나 집중호우가 발생할 가능성이 커짐 동시에, 해에 따라서는 고기압의 영향으로 가뭄이 발생할 수도 있는 고온다습 및 기후 변동성 특성을 보여줍니다.

연도별 기상 편차 비교: "연도별 상자그림(Box Plot)과 이동평균선을 함께 비교했을 때, 특정 연도에만 유독 기온이나 강수량의 편차가 컸던 이상 기후 현상이 관측되는가?"
기온 및 강수량 편차:
월별 일평균기온 분포를 나타낸 박스플롯을 보면, 겨울철(12~2월)과 환절기는 최저기온이 영하권(-5℃ 이하)까지 떨어지며 기온의 내부 편차가 매우 큽니다. 반면 여름철(7-8월)은 상자 폭이 좁고 높게 형성되어 고온 상태가 안정적으로 지속됩니다.
특정 연도 이상 기후:
2022년: 연중 강수량이 전반적으로 매우 적어 뚜렷한 가뭄 현상과 함께 연도별 편차가 극심했습니다.
2024년: 여름철 기온 최고점이 역대급으로 치솟으며 고온 현상의 강도가 유독 강하게 관측되었습니다.

강수와 기온의 상관성: "강수량이 집중되는 시기와 기온의 이동평균선 간에는 비가 올 때 기온이 일시적으로 떨어지는 역상관관계가 매년 일정한 주기로 반복되고 있는가?"
관계의 특성: 비가 올 때 일시적으로 기온이 낮아지는 단기적 역상관이 매년 일정한 주기로 완벽히 반복된다기보다는, 고온다습한 여름철 특성에 따른 복합적 상관관계가 나타납니다.
패턴 분석: 산점도와 월별 흐름을 보면 기온이 낮은 겨울·봄철에는 강수량도 함께 낮고, 기온이 가장 높은 여름철(고온기)에 대기 중 수증기량 증가로 인해 강수량이 함께 집중되는 양상을 보입니다. 즉, 기온이 높을 때 강수량의 스펙트럼이 최소 100mm에서 최대 500mm 이상으로 대폭 넓어지며 폭염과 폭우가 동시에 내재된 계절적 특성이 매년 반복되고 있습니다.


결측치/이상치가 무엇이며, 어떤 기준으로 처리했는지 설명할 수 있다.

1. 결측치 (Missing Values)란?
정의: 데이터 수집 과정에서 누락되었거나 기록되지 않아 비어 있는 값(Null, NaN 등)을 의미합니다. (예: 기상 관측 장비의 통신 오류로 특정 시간대의 기온이 기록되지 않은 경우)
처리 기준:
제거 (Deletion): 결측치가 전체 데이터에 비해 아주 적고, 분석 결과에 큰 영향을 주지 않는다면 해당 행(Row)이나 열(Column)을 삭제합니다.
대체 (Imputation): 데이터를 삭제하기 아깝거나 연속성이 중요한 경우 다른 값으로 채워 넣습니다.
일반적인 통계치(평균, 중앙값, 최빈값)로 대체
시계열 특화 방식(날씨 데이터에 적합): 결측치 전후의 데이터를 활용해 선형 보간(Interpolation)을 하거나, 앞뒤 값의 평균 또는 이동평균값으로 채워 흐름이 끊기지 않게 유지합니다.

2. 이상치 (Outliers)란?
정의: 정상적인 데이터 분포 범위를 크게 벗어나 유독 튀는 값입니다. 입력 실수나 기기 오작동으로 인한 '에러'일 수도 있고, 실제로 발생한 '극단적 현상(폭우, 폭염)'일 수도 있습니다. (예: 한국의 겨울철 기온이 갑자기 영상 50도로 기록된 경우)

처리 기준:
통계적 기준 (수학적 탐지):
IQR (사분위수 범위) 방식: 1사분위수(Q1)와 3사분위수(Q3)를 이용해 전체적인 분포 범위를 구한 뒤, 일반적으로 Q3+1.5IQR을 초과하거나 Q1-1.5IQR 미만인 값을 이상치로 판정합니다.
Z-score 방식: 평균에서 표준편차의 3배 이상 멀어진 데이터를 이상치로 간주합니다.
도메인 지식 (Domain Knowledge) 기준: 상식이나 과학적 사실에 비추어 불가능한 수치인지 판단합니다. 예를 들어 강수량이 음수(-)로 기록되었거나, 기온이 지구상 관측 범위를 벗어난 경우 무조건 오류(이상치)로 간주하고 제거하거나 보정합니다.

"수집된 데이터 중 기기 오류로 인해 발생한 결측치는 전후 데이터의 이동평균을 활용해 부드럽게 보간하였으며, 통계적 기준(IQR 1.5배 초과)과 기상학적 상식 범위를 동시에 적용하여 비정상적인 입력 오류(이상치)를 사전에 걸러냄으로써 분석 결과의 정확도를 높였습니다."

그래프에서 확인한 사실(관찰)과 해석(가설)을 구분해 말로 설명할 수 있다.
